MDA009 / VOYAGER CONTROL

A resub keeps the higher tier.

Until now, a Twitch Tier 2 sub or resub always ran SILVER FAST TRACK, and a Tier 3 sub or resub always ran GOLD FAST TRACK. Each one finishes by buying that membership, and the purchase removes the member from every other tier group. So a Gold or Platinum member who resubscribed at Tier 2 was moved down to Silver, and a Platinum member who resubscribed at Tier 3 was moved down to Gold.

This update makes each fast track check first. If the member is already in a higher Voyager tier, the fast track stops before it changes anything.

Sub or resubMember is alreadyWhat happens now
Tier 2 (Silver fast track)Gold or PlatinumNothing changes. They stay Gold or Platinum.
Tier 3 (Gold fast track)PlatinumNothing changes. They stay Platinum.
Tier 2 or Tier 3The same tier or lowerExactly as before.
What "nothing changes" covers.

When the fast track stops, it also skips its points credit, the purchase, the transfer to the giveaway bucket, the "has purchased" chat line and the upgrade animation, because the member is not buying a tier. The normal sub and resub points from your Currency System, the Fleet alert and the membership card are separate and still happen.

Install in Streamer.bot (one import)

  1. In Streamer.bot click Import and drag in Voyager_Fast_Track_Keep_Tier_Update.sb. It should list exactly two actions: SILVER FAST TRACK and GOLD FAST TRACK.
  2. Click Import and accept replacing the two existing actions. Their triggers (Twitch Sub and Resub, Tier 2 and Tier 3) are the same as before.
  3. Nothing else is touched: no code, no commands, no timers, no balances, no groups.
If you have edited either fast track yourself since Voyager's Points update, the import replaces your edits. In that case add the check by hand instead (below).

Or add it by hand

  1. Open SILVER FAST TRACK. Add sub-action Core › Groups › User in Group: user %user%, group GOLD GROUP. Drag it to the top.
  2. Under it add Core › Logic › If/Else: %inGroup% Equals True. Inside the true branch add Core › Logic › Break.
  3. Repeat both steps for PLATINUM GROUP, so the action starts with four sub-actions before "Set argument voyagerPurchaseOrigin".
  4. Open GOLD FAST TRACK and do the same once, for PLATINUM GROUP only.

Check it

  1. Pick a test account that is in PLATINUM GROUP. Right-click the SILVER FAST TRACK action's Twitch Resub trigger and choose Test Trigger with that account's name as the user.
  2. In Action History the run should show the group check and then stop. The account should still be in PLATINUM GROUP only, with the same points.
  3. Repeat with an account in BLUE GROUP: it should be fast-tracked to Silver as before.

Members already moved down

This update stops it happening again; it does not put anyone back. For a member who was moved down by an earlier resub, open Voyager Points › Member controls, choose the member, set their tier group back and apply.
