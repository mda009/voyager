ADDING A SOURCE

Same three steps for every one

  1. In OBS: Sources › + › Browser, name it after the row.
  2. Untick Local file; paste the address from Copy address; set the width and height shown on the row.
  3. Tick Shutdown source when not visible off, Refresh browser when scene becomes active off. Click OK — the row turns green within a few seconds.

The stage source goes above everything in every scene you stream from. Panels (leaderboard, community, goals strip) are shown and hidden from Live; where they sit is on Layout.

WHEN A ROW IS AMBER

Fixes

  • Right-click the source in OBS › Refresh cache of current page — Voyager updates change these pages.
  • Check the source is in the scene you are on and not hidden (eye icon).
  • If the address starts with file://, replace it with the address here — the host must serve the page for it to update live.
