MDA009 / STREAM IDENTITY

Your stream. Your control system.

The Voyager pages now share the look of your futuristic ticker: Rajdhani display lettering, deep navy panels, royal-blue edges and restrained cyan light. Your supplied Voyager, MDA009 and Unprofessionals logos appear throughout the operator pages and on-stream displays.

Visual refresh · No Streamer.bot import or C# compile

1. Preview it first

Extract the ZIP and open Preview_Voyager_Control.html. Use the top buttons to view Home, Giveaways, Points & Membership, Security and OBS Goals with sample data. The giveaway preview also shows the refreshed entrant and winner displays when you try a sample draw.

Each page keeps its existing filename and controls. The design uses your actual supplied logos. The complete font and logo assets are included in brand-assets, so the new branding works locally.

2. Update your existing working folder

  1. Make a backup copy of your current Voyager_Giveaway working folder.
  2. Copy the contents of the new Voyager_Giveaway folder into that same working folder. Replace the updated app files and include the entire brand-assets folder plus voyager-brand.css. Keep the folder structure; the HTML pages need the assets beside them.
  3. Keep your working config.js, stream-command-settings.js and stream-home-data.js if you have configured them. Choose Skip for those files during copying. They hold your connection, stream settings and saved analytics defaults. Updating in the same working folder also preserves the page locations used by your browser and OBS docks.
  4. Refresh your existing browser tabs and OBS docks. Your bookmarked files are still Giveaway_Control.html, Voyager_Command_Center.html, Voyager_Points.html and Voyager_Security.html.

No action import or C# compile is required for this visual refresh. Existing group membership, points, giveaway results, history and security reviews continue to use their existing data sources.

For each Voyager Browser source you already use, open its properties and refresh the current page/cache. Its local file and source dimensions stay the same:

The compact giveaway panel retains its five visible entrant rows, scrolling and transparent background. Small branding marks appear in the header and footer. Reveal and congratulations logos sit inside their existing animation containers, so they follow the same visibility and fade timing.

If an image or font is missing

Confirm brand-assets and voyager-brand.css sit beside your HTML files, then refresh the page. Copying only the HTML is not enough. The original transparent logo artwork is framed in CSS; the wide wing logos do not need manual cropping.

If an OBS dock still shows the old design, refresh that dock. If an on-stream source still shows it, refresh that Browser source too. The design preview uses sample data; open your existing live control page for actual stream operations.
