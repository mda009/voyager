Voyager Dreadnought setup

A chat co-op boss fight. You call the Dreadnought, chat types !join to board the Voyager fleet, then !fire to attack for free. Cheers and Super Chats fire missiles; gifted subs fire torpedoes, the biggest hits. If the fleet destroys it before time runs out, every pilot who fought earns the same Voyager points.

What you need

  • Voyager 2.17 or later, running (the fight runs in the Voyager host).
  • Streamer.bot connected in Voyager (Voyager Versus › Stream setup uses the same connection).
  • One new Streamer.bot action, Voyager - Dreadnought, below.

1. Create the action

  1. In Streamer.bot, Actions › right-click › Add. Name it exactly Voyager - Dreadnought. Untick Concurrent.
  2. Add a sub-action Core › C# › Execute C# Code. Delete the sample code, paste the whole of Voyager_Dreadnought.cs from your Voyager folder, click Compile (it should say "Compiled successfully") and Save and Compile.

2. Add the chat commands

  1. Commands › right-click › Add: !join (Permitted: Everyone), !fire (Everyone), and !dreadnought (Moderators and Broadcaster only). Tick Twitch, YouTube and Kick sources, and set a Global cooldown of 0 and User cooldown of 0 (Voyager handles the !fire cooldown).
  2. On the action, Triggers › right-click › Core › Commands › Command Triggered, once for each of the three commands.
  3. Voyager Versus also uses !fire during its own battles. That's fine: the Dreadnought only listens while a boss fight is running, and Versus is paused while one is on.

3. Add the support triggers

PlatformTriggers (on the same action)In the fight
TwitchCheer · Subscriptions › Gift Subscription · Subscriptions › Gift BombBits fire missiles; gifts fire torpedoes (a gift bomb counts once, not twice)
YouTubeSuper Chat · Super Sticker · Membership Gift1.00 of Super Chat counts like 100 bits; each gifted membership is a torpedo
KickGift Subscription · Mass Gift SubscriptionEach gifted sub is a torpedo (counted once per recipient)

4. Add it to OBS

  1. Add a Browser source, 1920 × 1080, address http://127.0.0.1:8740/dreadnought.html. Leave "Local file" unticked.
  2. In the source properties tick Use custom frame rate and set it to 60 (OBS browser sources run at 30 fps otherwise). Leave Shutdown source when not visible unticked, so the 4K textures stay loaded between fights.
  3. It is invisible until a fight starts. Options you can add to the address:
    • ?backdrop=0 for a transparent background over your gameplay (the ship, effects and glow stay).
    • ?quality=balanced (2K textures) or ?quality=low (1K) if your graphics card is short of memory. The default, ultra, uses 4K textures (about 650 MB of video memory).
    • For a 4K canvas set the source to 3840 × 2160 and add ?res=2.
    • ?fps=1 shows a frame counter while you tune it.
  4. The overlay targets 60 fps: if frames run slow it lowers its render resolution a little, and raises it again when there is headroom.

5. Try it

  1. Open Voyager Control › Voyager Dreadnought and click Preview (simulated chat). Nothing is posted in chat or paid.
  2. When you're live, click Call the Dreadnought (or a moderator types !dreadnought). Chat has the boarding time to !join; Start now skips the wait.
  3. Type !join and !fire yourself: the Streamer.bot checklist on the page ticks once events arrive.

6. Dreadnought & Versus stage (2.20.84 · Versus 2.20.91) — the screen takeover

When the Dreadnought is called, one browser source can take over the whole screen: the fight in the middle, your panels in the slots around it, a chat window, and your own scene shrunk into a corner, then everything returns after the battle report.

  1. OBS: in your live scene add a Browser source, 1920 × 1080, above every other source, address http://127.0.0.1:8740/control/stage.html (leave "Local file" unticked, tick "Use custom frame rate: 60"). It is transparent until a fight is called.
  2. OBS: put your game capture, camera and alerts in one nested scene or group inside the live scene (for example a scene called Game added as a source). This is what gets moved into the corner; the stage source and your Voyager overlays stay outside it.
  3. Streamer.bot: Actions › Add, name it exactly Voyager - Dreadnought Stage, add an Execute C# Code sub-action, paste Voyager_Dreadnought_Stage.cs, click Find Refs (adds the System reference the OBS calls need; otherwise Compile reports CS0012 about 'Uri'), Compile, Save. No triggers: Voyager runs it. Streamer.bot's OBS connection must be on. The same action (v1.4 and later) also switches Voyager's timed sources (Screen & overlays › Layout — a referral code shown for 30 s every 10 minutes, say), so paste it again after an update that mentions it.
  4. Voyager Control › Voyager Dreadnought › Dreadnought stage: pick what goes in each slot (Leaderboard panel, Community goal standings / goals / contributors, Hall of Fame, missions, Christmas panel, chat window, Squadron war panel, Dreadnought damage HUD, or a transparent camera window), what stacks in the bottom middle (giveaway goals strip, Right now ticker, command hints & medal toasts, Dreadnought damage HUD), how long the "Dreadnought called" splash holds before the takeover (6 s), how long the MVP celebration runs after the battle report (10 s), which OBS sources to hide while the stage is up (comma-separated names, e.g. your Versus ready timer and referral graphic; they come back afterwards), which corner your scene goes to, and type the live scene name and the game source name. Save, then Show the stage for 60 s to test the layout and the move.

Sequence: the splash slams over your full-screen game and holds; then your scene glides into the corner while the Dreadnought scene and panels build; boarding, battle and the battle report play; then the MVP (most damage) gets the screen — name in gold, damage, and on a victory the MVP bonus (Dreadnought settings › MVP bonus, 25 points by default, paid from Missions › Points owed like the other Dreadnought rewards) — before everything returns.

Voyager Versus uses the same stage: a !versus call brings the splash ("<caller> CALLS"), the arena takes the middle, and after the result the champion is celebrated for 10 s with the 50-point winner reward (an optional champion bonus, off by default, would be a payable on Missions › Points owed). Switch it, its splash hold, celebration length and bonus on the stage card; the standalone Versus arena source hides itself while the stage shows it.

While the stage is up the standalone Dreadnought, panel, goals-strip, moments and Christmas sources hide themselves so nothing doubles. The chat window shows Twitch, YouTube and Kick as Voyager hears them from Streamer.bot (no extra chat connection); platforms, !commands and names are switchable. chat.html also works on its own as an OBS source at any size. The move is scaled to your OBS canvas size (1080p, 1440p or 4K all put the window in the same corner), as long as the stage browser source itself fills the canvas. Without the Streamer.bot action the stage still shows; your scene simply stays where it is behind the picture-in-picture frame.

Rewards

Victory pays the same Voyager points to every pilot who fought (fired, cheered or gifted). They appear in Missions › Points owed and are paid with Pay all owed through the Points Ledger. Paid support only changes damage, never rewards, and the fight never gives giveaway tickets.

Balance (defaults)

SettingDefault
Hull4,000 + 350 per pilot (late pilots add 150)
!fire12–22 damage, every 4 seconds per pilot, 1 in 16 critical (×3)
Bits2.5 damage per bit (100 bits = 250)
Gifted sub600 damage
Battle60 seconds to board, 3 minutes to fight
BossShields at 50% (8 s, !fire halved), enraged at 20%, knocks pilots out for 10 s
Victory100 points each. If the Dreadnought escapes (or the fight is ended early) no points are awarded.

All of these are in Voyager Control › Voyager Dreadnought › Settings.
