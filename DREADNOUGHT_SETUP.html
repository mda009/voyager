Voyager Dreadnought setup

A chat co-op boss fight. You call the Dreadnought, chat types !join to board the Voyager fleet, then !fire to attack for free. Cheers and Super Chats fire missiles; gifted subs fire torpedoes, the biggest hits. If the fleet destroys it before time runs out, every pilot who fought earns the same Voyager points.

What you need

  • Voyager 2.17 or later, running (the fight runs in the Voyager host).
  • Streamer.bot connected in Voyager (Voyager Versus › Stream setup uses the same connection).
  • One new Streamer.bot action, Voyager - Dreadnought, below.

1. Create the action

  1. In Streamer.bot, Actions › right-click › Add. Name it exactly Voyager - Dreadnought. Untick Concurrent.
  2. Add a sub-action Core › C# › Execute C# Code. Delete the sample code, paste the whole of Voyager_Dreadnought.cs from your Voyager folder, click Compile (it should say "Compiled successfully") and Save and Compile.

2. Add the chat commands

  1. Commands › right-click › Add: !join (Permitted: Everyone), !fire (Everyone), and !dreadnought (Moderators and Broadcaster only). Tick Twitch, YouTube and Kick sources, and set a Global cooldown of 0 and User cooldown of 0 (Voyager handles the !fire cooldown).
  2. On the action, Triggers › right-click › Core › Commands › Command Triggered, once for each of the three commands.
  3. Voyager Versus also uses !fire during its own battles. That's fine: the Dreadnought only listens while a boss fight is running, and Versus is paused while one is on.

3. Add the support triggers

PlatformTriggers (on the same action)In the fight
TwitchCheer · Subscriptions › Gift Subscription · Subscriptions › Gift BombBits fire missiles; gifts fire torpedoes (a gift bomb counts once, not twice)
YouTubeSuper Chat · Super Sticker · Membership Gift1.00 of Super Chat counts like 100 bits; each gifted membership is a torpedo
KickGift Subscription · Mass Gift SubscriptionEach gifted sub is a torpedo (counted once per recipient)

4. Add it to OBS

  1. Add a Browser source, 1920 × 1080, address http://127.0.0.1:8740/dreadnought.html. Leave "Local file" unticked.
  2. It is invisible until a fight starts. Add ?backdrop=0 to the address for a transparent background over your gameplay, or ?res=0.5 if your PC struggles.

5. Try it

  1. Open Voyager Control › Voyager Dreadnought and click Preview (simulated chat). Nothing is posted in chat or paid.
  2. When you're live, click Call the Dreadnought (or a moderator types !dreadnought). Chat has the boarding time to !join; Start now skips the wait.
  3. Type !join and !fire yourself: the Streamer.bot checklist on the page ticks once events arrive.

Rewards

Victory pays the same Voyager points to every pilot who fought (fired, cheered or gifted). They appear in Missions › Points owed and are paid with Pay all owed through the Points Ledger. Paid support only changes damage, never rewards, and the fight never gives giveaway tickets.
