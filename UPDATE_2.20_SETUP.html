VOYAGER 2.20

Updating to 2.20 from 2.16

One pass for everything since 2.16: the Voyager Dreadnought boss fight (2.17), Voyager Medals (2.18), the new !voyager membership card (2.19) and naval ranks (2.20). About 30 minutes. Your points, tiers, !upgrade, purchases, giveaways and tickets are not changed by any of it.

Before you start

  • Close OBS scenes you're streaming from, and back up Streamer.bot (File › Export of all actions, or copy its data folder).
  • Have Streamer.bot and Voyager open on the streaming PC.

1. Update Voyager

  1. Right-click the Voyager tray icon › Check for updates and install 2.20.0 (or run Voyager-Setup-2.20.0.exe from the download page). Your data and settings stay where they are.
  2. Tray › Open Streamer.bot import files. Every .cs file below is in that folder.

2. Streamer.bot: update Stream Stats to v6

  1. Open the action Voyager - Stream Stats › its Execute C# Code sub-action. Replace all the code with Voyager_Stream_Stats.cs, Compile, Save and Compile.
  2. Yours is v5; v6 sends the sub and gift records that subscriber missions and season sub goals use.

3. Streamer.bot: add three new actions

For each: Actions › right-click › Add, name it exactly as shown, untick Concurrent, add Core › C# › Execute C# Code, paste the whole file, Compile, Save and Compile.

Action nameCode fileTriggers to add on the action
Voyager - DreadnoughtVoyager_Dreadnought.csCommand Triggered: !join, !fire (Everyone) and !dreadnought (Moderators/Broadcaster). Twitch: Cheer, Gift Subscription, Gift Bomb. YouTube: Super Chat, Super Sticker, Membership Gift. Kick: Gift Subscription, Mass Gift Subscription.
Voyager - MedalsVoyager_Medals.csCommand Triggered: !medals (Everyone)
Voyager - Membership CardVoyager_Membership_Card.csCommand Triggered: !voyager (see step 4) and Core › Groups › User Added to Group

Create the commands first in Commands › right-click › Add (!join, !fire, !dreadnought, !medals), tick Twitch, YouTube and Kick, and set the user and global cooldowns to 0 (Voyager handles cooldowns).

4. Streamer.bot: switch !voyager to the new card

  1. Action Silver Membership On Screen › Triggers: delete Command Triggered: !voyager.
  2. Action Voyager - Membership Card › Triggers: add Command Triggered: !voyager. In Commands, open SHOW CARD and tick Twitch, YouTube and Kick.
  3. Untick Enabled on Silver Membership On Screen, Gold Membership On Screen and Platinum OR Blue Membership On Screen. Leave every purchase, upgrade, FAST TRACK and Sub action as it is: your upgrade sounds still play, and the new card shows the tier-up.

6. Check it in Voyager Control

  1. Voyager Dreadnought › Preview (simulated chat). Then type !join in chat: the Streamer.bot checklist ticks.
  2. Medals › the checklist should show "Found the Voyager - Medals action" and "Medal data read". Past progress is awarded quietly with one line in chat.
  3. Membership cards › press each preview (Blue to Platinum, Stats, Medal wall, Tier-up, Promotion). Then type !voyager in chat.
  4. Review the settings: card upgrade prices (1,200 / 1,800 / 17,000, matching your actions), rank thresholds, which promotions show on stream, and which medal grades pop up.
