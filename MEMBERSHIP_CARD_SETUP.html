VOYAGER 2.19 · RANKS IN 2.20

Membership card setup

The new !voyager card is the glass card in each viewer's tier colour, built live from their points, leaderboard place, time watched, Versus record, season, Dreadnought fights, months subscribed and medals. It has two back sides (!voyager stats, !voyager badges) and a tier-up ceremony when someone joins Silver, Gold or Platinum.

What stays the same

  • Tiers and upgrades are unchanged. Your BLUE/SILVER/GOLD/PLATINUM GROUP, !upgrade, the Silver and Gold purchase actions, Silver > Gold and Gold > Platinum logic, the FAST TRACK sub rewards, the bucket accounts (mdavoyagersilver/gold/platinum), the threshold giveaways and your upgrade sounds all keep working exactly as they do now.
  • The card's next-tier bar uses the same prices: Silver 1,200 points, Silver → Gold 1,800, Gold → Platinum 17,000 (change them in Voyager Control › Membership cards if you change the actions).
  • Giveaway ticket balances are never shown.

1. Create the action

  1. In Streamer.bot, Actions › right-click › Add. Name it exactly Voyager - Membership Card. Untick Concurrent.
  2. Add a sub-action Core › C# › Execute C# Code. Paste the whole of Voyager_Membership_Card.cs, Compile, then Save and Compile.
  3. Triggers › right-click › Core › Groups › User Added to Group (any group; the code only reacts to SILVER, GOLD and PLATINUM GROUP).

2. Move !voyager to the new card

  1. Open the action Silver Membership On Screen › Triggers, and delete its Command Triggered: !voyager trigger.
  2. On Voyager - Membership Card, add Core › Commands › Command Triggered › !voyager. In Commands, open SHOW CARD (!voyager), tick Twitch, YouTube and Kick, and set the user cooldown to 0 (Voyager allows one card per viewer per minute).
  3. Disable (untick Enabled) these three actions so the old image cards stop appearing after an upgrade: Silver Membership On Screen, Gold Membership On Screen, Platinum OR Blue Membership On Screen. The purchase actions still run them, but disabled actions do nothing. Your upgrade sounds are in the purchase actions and still play.

3. OBS

  1. In your MDA Membership scene, hide or delete the old BLUE/SILVER/GOLD/PLATINUM Card, member name, member id and points balance sources.
  2. Add a Browser source, 1920 × 1080, address http://127.0.0.1:8740/card.html. Leave "Local file" unticked; tick Use custom frame rate: 60. Only the card is shown, nothing around it. Add ?frame=full to show the space scene around the card, or ?backdrop=0 to make the inside of the card see-through.
  3. Check it from Voyager Control › Membership cards with the preview buttons.

Naval ranks (2.20)

Every card shows a Royal Australian Navy officer rank earned by lifetime Voyager points (spending on upgrades never lowers it): Midshipman, Acting Sub-Lieutenant 5,000, Sub-Lieutenant 15,000, Lieutenant 40,000, Lieutenant Commander 80,000, Commander 150,000, Captain 300,000, Commodore 600,000, Rear Admiral 1,000,000, Vice Admiral 2,000,000 and top 10 all-time, Admiral 3,500,000 and top 3, Admiral of the Fleet 10,000,000 and #1 all-time (one holder). Promotions are announced in chat and, from Lieutenant Commander up, play a PROMOTED card on stream. Everything is adjustable in Voyager Control › Membership cards. No extra Streamer.bot setup.
