What the Lumia status means

Sent means the native CPH.LumiaSendCommand call returned. This API does not confirm physical light execution or that the shortcut exists. If nothing changes, check Streamer.bot's Lumia connection and the exact command name, then run that shortcut directly inside Lumia.

A playback cue is accepted only for a currently queued alert within five seconds of its scheduled start. Multiple sources and reconnects cannot send the same cue twice. A source loaded late can show the remaining animation without replaying old lighting. A failed or uncertain dispatch is not retried automatically. The visual alert continues even if Lumia fails.

Use this Voyager route for these five lighting events to keep it aligned with the visual queue. If Lumia already runs the same effects directly from Twitch events, disable those duplicate event bindings after testing this route; keep the shortcuts themselves.

Detailed PBR ships and guided torpedoes · v1.3

The hero Polaris now retains 519,842 hull triangles, up from 338,663. Its surface has 40 additional physical fittings: chamfered armour covers, fasteners, recessed vents and six twin-barrel turret fittings. These attach to the assembly sections and travel with them during the Build stage. Escort hulls retain 61,496 triangles and use an instanced detail pass.

New matched 4096 × 4096 PBR maps define base colour, tangent-space normals, cavity occlusion, roughness and metalness. Armour seams, service hatches, stencils, screws, thin scratches and worn metal edges share one layout. Paint stays mostly non-metallic; exposed fittings and thermal metal use a stronger metallic response. Clearcoat and glass highlights respond to the environment lighting.

Battle now launches three fully modelled VX-09 torpedoes. Each has a shaped casing, swept bevelled fins, collar rings, a seeker nose, a nozzle and a lit exhaust volume. Torpedoes eject, ignite, accelerate and steer along smooth curves; their orientation follows the flight path. Each arrival triggers its own expanding 3D fire/smoke meshes, brief light flash and spinning metal debris. The camera moves closer for launch and pulls back for impact, with sound cues retimed to the three launches and hits.

The output remains alpha-transparent and targets 60 FPS with adaptive resolution. PBR improves the real-time material response; this is a public concept-model-based render, not an official in-game asset or offline ray-traced film. Frame rate depends on the streaming PC and OBS workload.

How progression and the queue work

  • Each event plays its assigned stage. A subscriber can launch a ship even if their earlier follow was never recorded. A resub plays Battle immediately.
  • The roster records the highest observed stage. It never downgrades when a later event belongs to an earlier stage. It starts collecting after installation and is not a full subscriber history.
  • Gift bundles produce one fleet sequence. The giver's name and actual gift count appear. Twitch gift-bomb recipient notifications are suppressed. Kick uses its native mass-gift event. YouTube recipient welcomes are separate and can be disabled using the recipient trigger, as explained above. Up to five escort models represent the fleet visually, regardless of larger quantities.
  • Bits are fleet support. They trigger the Overcharge effect and accumulate in that account's bits total; they do not create a fifth membership progression stage.
  • Alerts play serially within this source. Timing is saved in Streamer.bot. If OBS is opened during an alert, it joins the current sequence; expired alerts are kept in history rather than automatically replayed.
  • Skip, clear and disable act on this queue only. Disabling also cancels scheduled animations. Native events are still recorded while output is disabled. Replay creates a new test-labelled animation without counting the support twice.
  • Giveaways and other overlays remain independent. There is no shared visual scheduler with winner or Versus animations, so those sources can appear at the same time.

Controls and records

The control page provides muted previews, a checkerboard/dark/light preview backdrop selector, preview frame timing, live OBS tests, sound volume, enable/disable, queue status, skip, clear, recent history, replay, roster search and JSON export. The preview FPS is measured in that browser tab and does not report OBS FPS. Volume changes affect subsequent sound cues; disabling or skipping stops the active sequence.

The dedicated persisted global is VoyagerFleetAlertsV1. It keeps the latest 500 alert records, up to 300 scheduled events, event totals and up to 50,000 identified captains. An event without an account ID can still play and count toward totals, but cannot be attached to a roster account. Anonymous gifts remain anonymous.

Back up Streamer.bot's persisted data alongside the Voyager folder. Export fleet record creates a readable snapshot for your records; it is not an automatic restore button. No viewer points, membership groups, game ships or rewards are granted by these alerts.
