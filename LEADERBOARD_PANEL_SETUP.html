Adding Voyager points to an existing panel

Follow POINTS_LEADERBOARD_UPDATE.txt. Update both Voyager - Stream Stats (v4) and Voyager - Leaderboard Panel (v1.1). Copying webpage files alone does not update Streamer.bot actions.

1. Update your Voyager files

  1. Back up your working Voyager folder and extract the new ZIP.
  2. Copy Voyager_Leaderboard_Panel.html, Voyager_Leaderboard_Panel.cs, Voyager_Leaderboard_Panel_Install.sb, Preview_Leaderboard_Panel.html, LEADERBOARD_PANEL_SETUP.html and all files beginning leaderboard-panel into your working Voyager folder.
  3. Replace Voyager_Command_Center.html and stream-command.js with the updated copies. The updated Preview_Voyager_Control.html includes an OBS leaderboard tab.
  4. Keep your working config.js, stream-command-settings.js, stream-home-data.js and twitch-analytics-data.js. The shared giveaway-connection.js, stream-command-model.js, stream-command-connection.js, giveaway-panel.css, voyager-brand.css and brand-assets folder must stay beside the new files.

You may copy the full folder over your existing copy instead, retaining those four configuration/data files. Reload your Home browser dock after copying.

2. Import the new display action

  1. In Streamer.bot, choose Import and load Voyager_Leaderboard_Panel_Install.sb.
  2. Import Voyager - Leaderboard Panel and its Voyager Leaderboard Panel queue. This is a new action.
  3. Keep the action enabled, Concurrent off, and assigned to that queue. The queue must be Blocking and unpaused.
  4. Open its Execute C# Code sub-action and click Compile → Save. References from your existing supplied setup are included. If compilation fails, copy the full error text.
  5. No triggers or timers are required for this new action. Keep exactly one enabled action named Voyager - Leaderboard Panel.

Your existing Voyager - Stream Stats v4 and Voyager - Community Tracker supply the leaderboard. If Home is already showing the correct community records, watch time, months and gift data need no further changes. Voyager points requires the v4 stats code. If it is empty, follow Native Community Setup first and check Leaderboard settings on Live dashboard.

3. Add the panel to OBS

  1. In the scene, add a new Browser source named Voyager Leaderboard.
  2. Tick Local file and select Voyager_Leaderboard_Panel.html from your working Voyager folder.
  3. Set Width 1920 and Height 1080. Keep the source at canvas position X 0, Y 0 with no cropping. For a differently sized canvas, scale this 1920 × 1080 source to fit.
  4. Keep the source eye enabled, then click Refresh cache of current page once. The source remains transparent until you show a leaderboard from Live dashboard.
  5. Open Live dashboard → Community leaderboards, select a leaderboard/platform, and press Show in OBS.

The default panel is 356 px wide, 16 px from the right, 132 px from the top, with 40% background opacity. It occupies the same area as your giveaway panel. Hide one before showing the other, or change the leaderboard position in its panel settings.

4. Adjust the panel

Open Panel settings & preview on Live dashboard. The preview uses the currently loaded Home records. It is shown centrally for inspection; OBS uses your top/right placement.

What the numbers mean

  • Watch time: with native tracking, this is estimated live chat presence accumulated since tracking was installed, not verified video-viewing time. The panel labels it accordingly.
  • Subscription months: observed subscription tenure received from platform events, not the number of currently active subscriptions.
  • Gifted subs: Twitch uses shared cumulative totals when reported. YouTube/Kick use gifts observed since tracking. These are not a complete private historical gifting database.
  • Voyager points: the current saved points balance for each Twitch, YouTube or Kick account, after spending and adjustments. The Silver, Gold and Platinum Twitch bucket accounts are excluded. These balances are read automatically, independent of native/custom watch-time settings. This is not a lifetime earned total or Twitch Channel Points.
  • Custom sources: use the same configured variables, units, exclusions and ranking as Home. A custom source must contain the data you want to show.
  • Rows show rank, initials, account name, platform icon and total. The existing leaderboard records do not include profile photographs or verified cross-platform account links.

While shown, the OBS page reads saved leaderboard data every 60 seconds, even with Home closed. Display settings synchronize every 30 seconds and on connected update events. Closing Home does not hide the panel.

If the panel is empty or does not update

SymptomCheck
Show/Hide disabledInstall and compile the new action; check its name, enabled state and queue. In Panel settings use Refresh connection. Streamer.bot’s WebSocket server must be running.
Home shows the panel but OBS is blankCheck the local HTML filename, selected scene, source eye and auto-hide timer. OBS and Home must connect to the same Streamer.bot instance. The overlay uses config.js; Home connection overrides do not change that file.
Loading / unavailable / no recordsCheck Stream Stats, Community Tracker and Home’s Leaderboard settings. If Home changed sources, Show or Save again. Missing records are displayed as unavailable, not invented zero totals.
Last known / PartialLast known means the source or control connection failed, a read failed, or data became stale. The previous values remain visible while reconnecting. Partial means only part of the requested data is available or source coverage is limited.
Another dock changed the panelRefresh and use Load saved panel settings before applying your edits again. This avoids silently overwriting a newer update.
Update not confirmedRefresh and inspect the saved state before retrying. Reconnect never automatically repeats a settings change.

If a source disconnects, Hide cannot reach it until it reconnects. Use the OBS eye icon to remove it immediately. A configured auto-hide still runs in an already loaded page.

Saved settings

The new persisted global VoyagerLeaderboardPanelV1 stores visibility, appearance, source choices and auto-hide expiry. Include persisted globals in Streamer.bot backups. This action does not change member points, giveaway pools or community totals.
