Are tickets earning?

Presence events award the time. Chat entry alone does not start an independent timer. Each account below shows its saved minutes and progress toward its next ticket.

Match Platforms → Twitch → Settings → Present Viewers in Streamer.bot. Use 1 minute for faster updates. This control changes Voyager's expected interval, not Streamer.bot's setting. YouTube and Kick presence events run every minute; their slider controls recent chat activity.
