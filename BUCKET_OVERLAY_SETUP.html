VOYAGER / GOALS HD

Clear at every resolution.

The Silver, Gold and Platinum strip now matches the Live OBS overlay: larger Rajdhani type, precise borders, clean progress bars and a translucent navy surface. Text and bars render directly at your Browser Source resolution. Your original high-resolution Voyager, MDA009 and Unprofessionals logos are retained.

3840 × 480 source · Same Points Ledger · No C# compile

Install the small update

  1. Extract Voyager_Bucket_HD_Update.zip directly into your existing Voyager_Giveaway folder. Allow matching files to be replaced. If you downloaded the full Studio package, the same small ZIP is included inside it.
  2. Keep your existing config.js, points settings and saved data. The update only contains presentation files, this guide, a preview, and the existing fonts/logos.
  3. In OBS, open Properties for your existing goals Browser Source. Continue using Voyager_Bucket_Overlay.html from your working folder.
  4. Set Width: 3840 and Height: 480. Use 30 FPS; 60 FPS is optional for the bar transition. Click Refresh cache of current page.
  5. Resize the source in your scene to suit your layout. The examples below retain a compact strip at the top. Refreshing the file without changing the old 900 × 110 source resolution will not give you a 4K render.

No Streamer.bot import, C# compilation or launcher restart is required for this visual update. The existing Points Ledger connection and its automatic recovery are unchanged.

OBS source and scene sizes

The Browser Source renders at 3840 × 480. Its transparent canvas is a strip, not a full-screen 3840 × 2160 page. Scale it down in your scene. The text and bars have no bitmap texture limit; the logos are the existing supplied PNGs.

Keep Shutdown source when not visible and Refresh browser when scene becomes active unticked to maintain the connection across scene changes. Use the standard transparent Browser Source Custom CSS.

Transparency and preview

The surface is 35% opaque; the rest of the page is fully transparent. A design preview includes the values from your screenshot, over-target balances, empty buckets and resets. Preview mode is labelled SAMPLE DATA and does not connect to Streamer.bot.

If using a hosted URL, append ?opacity=25 for a lighter surface or ?opacity=50 for stronger contrast. For Local file sources, you can adjust --surface-opacity:.35 near the top of bucket-overlay.css. This affects the panel background, not the text.

If it still looks soft or old

  • Confirm Width is 3840 and Height is 480 in Browser Source Properties, not only in Edit Transform.
  • Refresh the source cache. The updated HTML loads the versioned HD stylesheet.
  • Check brand-assets contains all three Rajdhani fonts. They are bundled locally and need no internet connection.
  • Scale down from the 4K source. Avoid enlarging the old 900 × 110 render.
  • Remove any blur filter you added to this source. Very small text will still lose detail in the final streaming resolution and video compression; make the strip larger if needed.
  • Connection issues: open Points & Membership from the same folder and check the Points Ledger action and queue.
