Add it to your Fourthwall store

  1. In Fourthwall, open Site design › Layout, open the page drop-down and choose Create page. Name it Voyager.
  2. Click Add page section › Custom code, paste the code below, tick Full width and save.
  3. Add the Voyager page to your store menu so viewers can find it.
