ON STREAM

The run

—
Press Start a run. A contract card appears and anyone who types a command during the run is on the crew.
!minePhase 1. Keeps a miner's laser on for 10 seconds. About half the miners at a time holds the charge in the green window; everyone at once overcharges it and loses ore.
!firePhase 2. Pirates pull the freighter out of the jump. Every hit counts; the longer the pirate lives, the more cargo is shot loose.
!sellPhase 3. The price swings. The cargo sells the moment half the crew (20 at most) has typed it.

Add it in OBS once: Browser source, 1920 × 1080 (any 16:9 size works), at this address. It is invisible until you start a run, and viewers cannot start one — not from chat and not from the website. Each person's command counts once every 6 seconds, so chat stays inside the platforms' limits.

Stage takeover (2.38): if the game stage source is in OBS (Dreadnought › Stage takeover), a run plays there exactly like the Dreadnought: the splash slams in, your scene shrinks to the corner, the panels arrive around the game, and the MVP is celebrated at the end. This source then steps aside by itself. Switch it per game on the Stage takeover tab.
