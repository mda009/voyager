- Updated transparent compatibility artwork for browsers without WebGL.

INSTALL THIS GRAPHICS UPDATE
1. Stop the Voyager launcher and close the game/control tab.
2. Keep a backup of your current Voyager_Versus folder.
3. Open the new package's Voyager_Giveaway folder. Copy ONLY its
   Voyager_Versus folder into your existing Voyager_Giveaway folder.
   Merge the folders and replace matching program files.
   KEEP your existing Voyager_Versus/local/data folder and all its files.
   Do not delete or replace the entire old game folder first.
   This update contains no local/data files.
4. Start your usual START-VOYAGER-CONTROL.bat or START-VOYAGER.bat again.
5. Reload the Voyager Versus tab. Check V2.2.0 beside the title.
6. In OBS, open the Voyager Versus Browser Source properties and choose
   Refresh cache of current page. Reopen the properties if needed.
7. Launch a demo and check motion, weapons and frame rate on your stream PC.

4K OBS SETUP
In the game's Stream setup, choose OBS graphics quality and copy the resulting
URL into your OBS Browser Source. Keep Local file unchecked.

Ultra (default): 4096px maps; up to 3840px rendering width.
http://127.0.0.1:8740/?overlay=1&hideIdle=1&quality=ultra
For native 4K output, set source Width 3840 and Height 2160. Start at 30 FPS;
try 60 FPS if the streaming GPU has sufficient headroom.

Balanced: 2048px maps; 1920px rendering cap.
http://127.0.0.1:8740/?overlay=1&hideIdle=1&quality=balanced
Use a 1920 x 1080 source. Recommended if recording or gameplay already uses
most of the GPU. This mode scales up if the OBS source is larger.

Low: 1024px maps; 1280px rendering cap.
http://127.0.0.1:8740/?overlay=1&hideIdle=1&quality=low

Changing the quality selector changes the generated OBS URL. It does not
change an already-open OBS source until you paste that URL there. To change
the control page quality too, open http://127.0.0.1:8740/?quality=balanced
(or quality=low). The embedded control defaults to Ultra.

4K textures describe the material resolution. A 1920 x 1080 OBS source still
outputs 1080p even with Ultra selected. Your OBS canvas/output resolution
also determines the final stream resolution. The overlay stays transparent.
