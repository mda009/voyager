UPDATE YOUR EXISTING INSTALLATION
1. Extract this ZIP. Merge Voyager_Giveaway into your existing folder.
   Keep your current config.js; it is not included in this patch.
2. In Streamer.bot open the EXISTING Voyager - Fleet Alerts action and its
   Execute C# Code sub-action. Replace all code with Voyager_Fleet_Alerts.cs.
   Compile, save and close. Keep the existing references, action name, running
   Voyager Fleet blocking queue and Concurrent OFF. Do not add a duplicate action.
3. On that SAME action, right-click Triggers and add:
       Twitch > Raid > Raid
   This is the INCOMING raid trigger. Leave Min / Max blank for every raid.
   Add it once. Raid Start / Send are outgoing events and will not play this alert.
   The supplied .sb is for first installations; its original six Twitch triggers
   are included, but you must still add this incoming Raid trigger manually.
4. OBS: refresh the cache of your existing Voyager_Fleet_Overlay.html Browser Source.
   Reopen Voyager_Fleet_Control.html. No extra OBS source is required.
5. Select 06 / Raid, enter a raiding channel display name and number of raiders,
   then Send test to OBS. Confirm the full 28-second animation and final fade.
   Use Clear queue if earlier alerts/tests are waiting. The raid shares the
   existing serial alert queue; it waits for an earlier alert to finish.
