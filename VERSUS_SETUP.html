Voyager Versus is in Control.

Open Voyager Versus from the sidebar on Home, Points & membership, Giveaways, Security or Banner. The game shares one local host with its OBS overlay, so changing pages never starts another battle.

Updating an existing installation: stop the current game launcher first. Keep your existing config.js, stream-command-settings.js and any saved settings exports. Replace program files with this package. If you used the standalone Versus game, copy its existing local/data folder into Voyager_Giveaway/Voyager_Versus/local/data before starting this version. This preserves rankings, pending rewards, cooldowns and announcement receipts. Keep only one game host running.

v2.0 rules update: 45-minute global cooldown; 50 points for the winner and 0 for the runner-up. Existing installations must update and compile the rewards code, then rename the action Voyager Versus Rewards v2.5. Follow the update instructions before restarting.

Launch from the Control page

  1. Keep the whole extracted Voyager_Giveaway folder in its permanent location.
  2. Once on your Windows streaming PC, double-click SETUP-VOYAGER-LAUNCH-LINK.bat in that folder. Node.js 22.4 or newer must be installed. This registers the Voyager launch link for your Windows account; it does not require an administrator or change PowerShell policy.
  3. Open Voyager Control normally, including directly from its HTML file. Click Start Voyager Versus on Home or the Voyager Versus page.
  4. Allow your browser to open the Voyager launcher if prompted. It starts the local game and opens the live Voyager Versus page in Control. If the host is already running, it opens the existing game without restarting it.

Keep the game console open while streaming. The launcher does not start a battle or award points by itself; viewers still use !versus. Your START-VOYAGER.bat shortcut and the page button use the same launcher. START-VOYAGER-CONTROL.bat opens Home through that launcher.

If the browser says no application is installed, run setup once and click again. If you move the folder or reinstall Node.js, rerun setup from the current folder. To remove the browser link, run REMOVE-VOYAGER-LAUNCH-LINK.bat; this leaves the game and data intact. On macOS/Linux, use the existing shell launcher.

The button uses the Windows voyager-versus: launch link. Only the fixed Voyager launcher is registered. URLs cannot supply commands, filenames, ports or a page address. The normal browser confirmation stays enabled.

Manual launch and first game setup

  1. Install Node.js 22.4 or newer if needed, then extract the whole package.
  2. Double-click START-VOYAGER-CONTROL.bat inside Voyager_Giveaway. On macOS/Linux, run sh start-voyager-control.sh.
  3. The Home dashboard opens at http://127.0.0.1:8740/control/Voyager_Command_Center.html. Choose Voyager Versus in the menu. Keep the launcher window open.
  4. In the embedded game's Stream setup tab, connect to your Streamer.bot WebSocket server.
  5. For an existing installation, replace the code in your current rewards action with the updated file, compile/save, and rename it exactly Voyager Versus Rewards v2.5. For a first installation, create that action, add Execute C# Code using Voyager_Versus_Rewards.cs, compile/save, and assign a dedicated blocking queue with no chat trigger. This action handles the 50/0 rewards and availability announcement.

Your other Control pages use their existing connections and config files. Browser-only settings saved under a file URL are separate from settings under localhost; export them before switching or enter them again if required. Stored points, groups and giveaway records stay in Streamer.bot.

Transparent splash and OBS

Add a Browser Source with Local file unchecked. Use http://127.0.0.1:8740/?overlay=1&hideIdle=1, at 1920 × 1080. The calling splash, countdown, ships, results and pause screen have no background panels. Text, logos and effects float on your stream. After updating, refresh the OBS Browser Source cache. No transparency switch or chroma key is needed.

During the launch countdown and battle, the overlay displays !fire, !missile, !shield and !dodge beneath the ships, plus their recharge times. The footer shows !leave to forfeit. Only the two active pilots can fight, and weapons unlock when the countdown ends. This guide is fully transparent and hides during the calling splash, idle arena and results. Keep the same battle overlay URL; restart Voyager and refresh the OBS source cache after updating.

Next-game cooldown overlay

  1. Stop the previous game host, update the program files while keeping Voyager_Versus/local/data and your configuration files, then relaunch Voyager Control.
  2. On the Voyager Versus page, scroll to OBS / Next battle timer and click Copy timer URL.
  3. In OBS, add a separate Browser Source called Voyager Versus Cooldown, leave Local file unchecked, and paste http://127.0.0.1:8740/cooldown.html. Use your configured port if different.
  4. Set width to 640 and height to 240. Move and resize it wherever you want on the scene. The background is completely transparent. No chroma key or custom CSS is required.

It counts down the same saved 45-minute cooldown as the game. When the timer expires, it shows READY with a !versus prompt if entries are open, the arena is idle and Streamer.bot is connected. Pauses, closed entries, active battles and connection losses show the matching status. An open call can still accept its second pilot immediately, even while the next-call timer is running.

Keep the host running. Refreshing OBS or changing scenes never resets the deadline; restarting the host reloads it from disk. Training previews do not consume the live cooldown. The Preview timer link shows a labelled 12-second sample without changing the game. The live OBS URL must not include ?preview=1. Refresh the OBS Browser Source cache after updating.
