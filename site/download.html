Before you install

Windows 10 or 11 (64-bit)

Install it on the same PC that runs OBS.

Streamer.bot

Turn on its WebSocket server. A password is recommended.

OBS Studio

Overlays use http://127.0.0.1:8740, the same addresses as before.

Install

  1. Run the installer and choose where to put Voyager.
  2. On first start, choose your existing Voyager folder to bring over rankings, rewards and config.js. Your old folder is not changed.
  3. The System check opens. Fix anything red, then you are ready to stream.
  4. Closing the window keeps Voyager running for OBS. Use the tray icon to reopen or quit it. Updates install automatically when you quit.
