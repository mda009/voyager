Requests

    A request arrives a few seconds after the viewer sends it. Each viewer can ask for each option once per stream. Clearing lets everyone ask again; the entries stay in the log.

    OBS

    The alert overlay

    Add a Browser source, 1920 × 1080, above your other sources, with this address. When a request arrives a paper plane flies in across the screen and bursts into a gold card at the top: who asked, what for, and how many are asking. It plays a chime if that is switched on (in OBS, tick Control audio via OBS on the source to hear it on stream).

    The website cannot prove who is typing, so a request carries the card name the viewer picked. Voyager only accepts names on your crew list, one request per option per name and per device each stream, a cap per network per day, and only from your list above — there is no free text to moderate.
