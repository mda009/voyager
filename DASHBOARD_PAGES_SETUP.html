Update your current Voyager folder

  1. Close the Voyager browser tabs and OBS control docks.
  2. Extract the new package into a temporary folder. From its Voyager_Giveaway folder, copy the files in the list below into your existing working Voyager_Giveaway folder, accepting replacement for those files.
  3. Keep your existing config.js, stream-command-settings.js, stream-home-data.js and twitch-analytics-data.js. This layout update contains no changes to your Streamer.bot C# actions, groups, points or giveaway data. There is no new action to import or compile for this change.
  4. Reopen your existing Home bookmark or OBS dock, and refresh it. Select Live dashboard or Reporting in the sidebar. If old content remains cached, press Ctrl+F5 in your browser or refresh the OBS dock.

Where everything lives

PageContents
HomeConnection and data readiness, shortcuts to the other dashboards and stream tools, membership group counts and the current giveaway summary.
Live dashboardLive pulse, combined and per-platform viewer counts, followers and subscriptions, goals, the current-session audience chart, live Twitch chat metrics, community leaderboards, leaderboard OBS controls and recent activity.

Reporting keeps Previous 30 days as its default CSV view, with Previous 14 days, Previous 7 days, Latest stream and individual saved reports available. External public figures refresh when Reporting opens and every 30 minutes while it stays open, using the existing External Analytics action and cache rules.

The daily performance chart now uses uploaded Twitch daily reports when available and displays calendar dates through yesterday, including explicit gaps for missing figures. Its Reporting window control also updates the report cards below. Chart date update and troubleshooting.

Your existing data stays available

The three dashboards use the same underlying Command Center document and saved-data keys. The page address adds a page selection, preserving access to data saved at your existing Home address. Use the new navigation from that existing folder and browser. The dedicated entry files below redirect to the matching view.

Browsers, OBS, and local-file versus localhost addresses can have separate storage. Continue using the same address style as before. To transfer data between them, use the existing settings and report export files. Do not clear browser storage during this update.

Separate OBS docks

You can keep all three open as separate Custom Browser Docks. Open this guide from your actual working Voyager folder, then copy the appropriate address below into OBS → Docks → Custom Browser Docks. The buttons calculate addresses for this installation.

Convenient entry files: Voyager_Live_Dashboard.html and Voyager_Reporting.html. Home remains Voyager_Command_Center.html.

Existing integrations

Live dashboard uses your installed Stream Stats, native community tracker, Twitch chat tracker and Leaderboard Panel actions. Reporting uses the existing External Analytics action and the Twitch chat tracker for captured history. If a previous feature was not installed, its setup guide remains linked from its new page. The Voyager Versus launcher remains on Home.
